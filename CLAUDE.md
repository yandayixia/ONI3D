# CLAUDE.md

## Git workflow

- **Commit titles come from the user.** Before committing, ask for the title; never invent one.
- **Commit body:** a clean, short summary of the changes (a few lines), followed by the required `Co-Authored-By` trailer. Show the full message before committing.
- **Never push automatically.** Run `git push` only when the user explicitly asks for that push; approval for one push does not carry over to the next.
